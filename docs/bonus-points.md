# Assessment bonus points

| Bonus | Project status | What to show or explain |
| --- | --- | --- |
| SharePoint | Implemented as a mock endpoint at `GET /api/announcements` | Show the Announcements page and explain that live Microsoft Graph access needs a tenant and Entra permissions. See [SharePoint integration](sharepoint-integration.md). |
| PNG chart export | Implemented through the Plotly chart toolbar | After analyzing a CSV, hover over a chart and use its camera button to download a PNG. |
| Microsoft Fabric readiness | Architecture documented; no Fabric workspace connection | Explain the Bronze, Silver, and Gold path in [Fabric readiness](fabric-readiness.md). |
| Voice-agent architecture | Architecture documented; this assessment app remains text-only | Relate the design to the separate Nova voice-agent project. See [Voice assistant architecture](voice-agent-architecture.md). |

Only the SharePoint sample endpoint and the chart export run in this local demo. Fabric and voice are design proposals, not deployed integrations.
